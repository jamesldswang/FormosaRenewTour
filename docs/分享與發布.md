# 分享與發布說明

## 一、傳檔案給合作夥伴（草稿階段建議用這個）
1. 點兩下專案資料夾裡的 `build.bat`（三種語言都包在同一個檔案裡，對方可在右上角切換）
2. 到 `dist/` 找到 `FormosaRenewTour-v版本號.html`
3. 用 LINE、Email 或 Google Drive 傳給對方，對方點兩下就能用瀏覽器開

> 手機上 LINE／Gmail 有時只能預覽、不能直接開，請對方先「下載」再用瀏覽器開啟。
> 也可以從 GitHub Release 頁面直接下載這個檔案。

## 二、放上網路給網址（確認內容後再做）
放上網路就等於公開，醫院資料與價格確認前不建議公開。

| 服務 | 做法 |
|---|---|
| Netlify Drop | 到 app.netlify.com/drop，把整個專案資料夾拖進去 |
| GitHub Pages | repo 設定 → Pages → 選 main 分支（private repo 需付費方案，或改成 public） |
| 自訂網域 | 買 formosarenewtour.com 等網域，接到上面任一服務 |

## 三、發布新版本（Release）
```bash
# 1. 改 data.js 的 SITE_VERSION，例如 1.1.0；CHANGELOG.md 新增一段
# 2. 打包
node build.js
# 3. commit 與 tag
git add -A
git commit -m "Release v1.1.0"
git tag -a v1.1.0 -m "v1.1.0"
git push origin main --tags
# 4. 建立 GitHub Release，附上打包檔
gh release create v1.1.0 dist/FormosaRenewTour-v1.1.0.html --title "FormosaRenewTour v1.1.0" --notes "（貼上 CHANGELOG 這版的內容）"
```

### 版本號規則（語意化版本）
- **主版號** 1.x.x → 2.0.0：大改版（例如改版型、加多語系）
- **次版號** 1.0.x → 1.1.0：新增功能或區塊（例如新行程、評價區）
- **修訂號** 1.0.0 → 1.0.1：修正錯字、更新價格或醫院資料
