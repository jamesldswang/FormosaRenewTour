# Formosa Renew

外國旅客來台「旅遊 + 醫療 / 醫美」網站（英文版）。純靜態網頁，雙擊 `index.html` 即可開啟。

## 檔案
- `index.html` — 頁面結構
- `styles.css` — 樣式（玉綠 + 金色主題，支援手機）
- `data.js` — **所有內容資料**：行程套裝、參考價格、醫院清單、醫美恢復期、FAQ。改內容只要改這個檔。
- `app.js` — 篩選、表單等互動
